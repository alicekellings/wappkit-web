# License Retrieval Without a User Dashboard

Not every software business needs a customer dashboard.

For Wappkit, the cleaner model is:

1. purchase with checkout
2. receive a license
3. activate inside the app
4. recover the key later with order details and email

## Why this is better for lightweight tools

- less friction
- lower support cost
- fewer authentication problems
- easier product maintenance

Shopify allows product images up to 5000 x 5000 pixels or 25 megapixels, whichever limit you hit first, with a hard file size ceiling of 20 MB. That's the documented maximum, confirmed on Shopify's own product media page. It's not, though, the size you should actually upload.

For most square product photos on Shopify, 2048 x 2048 pixels is the real sweet spot. It keeps you well clear of both the pixel ceiling and the 25-megapixel trap, while still giving Shopify's CDN enough resolution to generate crisp zoom and thumbnail variants, without forcing shoppers to download an oversized file on a mobile connection. This article measures the published specs across Shopify and three major marketplaces, shows where the 5000px number actually comes from, and explains why bigger isn't safer once you look at how the megapixel math works.

## What Was Measured and How

This is a documentation audit, not a crawl of live store images. The sample is the current, publicly accessible product-image specification pages for four platforms: Shopify, eBay, Etsy, and Walmart Marketplace. Each page was checked against its live state in November 2026, the same window this article was published.

For each platform, three figures were pulled directly from the official help documentation where available: maximum pixel dimension, maximum file area or file size, and any explicitly recommended (not just maximum) dimension. Where a platform publishes a minimum instead of a maximum, that's noted separately, since minimums and maximums solve different problems.

No performance benchmarks, load-time tests, or conversion data were generated for this report. Those numbers would require a live store crawl with a defined sample size and date window, which wasn't run here. Every figure below is traceable to a specific help page, not an estimate.

## What the Numbers Mean, Platform by Platform

The 25-megapixel trap is the part most sellers miss. 5000 x 5000 px equals exactly 25,000,000 pixels, which sits right at Shopify's stated area ceiling. A non-square image that's 5500 px wide and 4600 px tall stays under 5000px on each individual axis, the check most sellers actually run, but it can still clear 25 megapixels in total area and get rejected or auto-compressed in ways you didn't choose.

Checking width and height against 5000 separately isn't enough; the area math is the real gate, as Shopify's own documentation states.

That's one reason tools built specifically for this check matter. The [Shopify Product Image Checker](/tools/shopify-product-image) validates both the 5000px ceiling and the 25 megapixel area limit together, along with the 20 MB file cap, so you catch a near-miss before upload instead of after a failed import.

For eBay sellers, the direction flips. eBay's documented concern is a 500 x 500 px minimum, not a maximum worth worrying about. If you're repurposing the same source file across channels, an image sized for Shopify's 2048px sweet spot clears eBay's floor with enormous margin. The [eBay Photo Checker](/tools/ebay-photo) confirms that minimum alongside the 12 MB ceiling and 24-photo-per-listing cap, which matter more for eBay than any upper pixel bound.

Etsy's number is the one most sellers misread. The 635px figure isn't an upload limit at all, it's a search-ranking threshold tied to how Etsy's algorithm evaluates listing image quality. Etsy will accept images well below and well above that number; 635px is simply the floor where ranking starts to improve. The [Etsy Listing Image Checker](/tools/etsy-listing-image) flags this distinction directly, since treating a ranking signal as a hard requirement leads sellers to either underthink or overthink their resizing.

Walmart sits in the middle. Its 2200px square target and 1500px zoom threshold land closer to Shopify's 2048px recommendation than to Shopify's 5000px ceiling. That overlap isn't a coincidence, it reflects the same underlying constraint: zoom features need enough resolution to crop and magnify without visible softness, but nothing close to 25 megapixels of source data. The [Walmart Main Image Checker](/tools/walmart-main-image) checks that 2200px target alongside the 5 MB file cap, a fraction of Shopify's 20 MB allowance.

## Where This Data Is Weak or Could Mislead You

The published specs tell you what each platform will accept. They don't tell you what each platform's CDN does to your file afterward, and that gap is where most confusion starts. Shopify's own documentation doesn't publish a guaranteed compression ratio, delivery resolution, or page-speed impact figure for images between 2048px and 5000px, so any specific load-time number you see elsewhere is an estimate, not a documented fact.

The 2048px recommendation itself is also worth treating carefully. It's a widely repeated practical target among Shopify theme developers and performance-focused merchants, not a separately enforced limit sitting inside Shopify's spec page the way 5000px and 20MB are. Shopify will accept a 3500px image without complaint. The 2048px figure is a tradeoff recommendation, not a rule, and your theme's actual image handling can shift the ideal number up or down.

Minimums and maximums also don't transfer across platforms the way sellers assume. A file that clears Shopify's 25-megapixel ceiling with room to spare can still fail Etsy's or eBay's separate file size caps if you didn't check those limits independently. Cross-platform sellers need to verify each destination on its own terms, not assume one safe size covers every channel.

## Action Checklist From the Table

Translating the table into upload habits is straightforward once you separate ceilings from targets. For a Shopify-only catalog, resize to 2048 x 2048 px for square product shots, confirm the file lands under 20 MB, and manually multiply width by height any time you work with a non-square crop to make sure you're not quietly crossing 25 megapixels.

Multi-channel sellers have a slightly longer list, since each marketplace enforces its own floor and ceiling independently. On Shopify, stay near 2048px square with a hard ceiling at 5000px or 25MP and keep files under 20MB. On eBay, stay above the 500px minimum and under 12MB; there's no real upper pixel concern. On Etsy, treat 635px as a ranking floor rather than an upload rule, and resize for quality instead of compliance. On Walmart, target 2200px square with the 1500px zoom threshold in mind, and keep files under 5MB.

Run each image through the checker built for its destination platform before upload, since catching a megapixel or file size mismatch before submission is faster than fixing a rejected listing afterward. If you manage product photography across several marketplaces at once, a tool like [AI Ecom Visual Studio](/tools/ai-ecom-visual-studio) can batch-resize and validate images against these platform-specific ceilings in one pass instead of checking each file manually.

## FAQ

### What is the actual maximum file size for Shopify product images?

Shopify's documented maximum is 20 MB per image, alongside the 5000 x 5000 px dimension ceiling and the 25-megapixel area limit. All three limits apply at once, so a file can fail on area or file size even if it passes the pixel-dimension check.

### Why is 2048x2048px recommended over 5000x5000px?

2048px gives Shopify's CDN enough resolution to render sharp zoom and thumbnail crops without forcing a near-maximum file through every page load. 5000px is accepted but sits at the platform's absolute ceiling, which means larger uncompressed file sizes with no proven quality gain for typical product photography.

### Does using smaller images hurt the zoom feature on my product page?

Not at 2048px. That resolution is well above the thresholds marketplaces like Walmart publish for reliable zoom rendering, which sit closer to 1500 to 2200px. Zoom quality degrades at much lower resolutions, not at 2048px.

## Conclusion

Shopify's 5000px and 25-megapixel ceilings are real, but they describe the edge of what the platform will accept, not what it performs best with. The documented numbers across Shopify, eBay, Etsy, and Walmart point to the same practical lesson: resize for the platform's actual rendering needs, usually around 2048px for Shopify, and check the megapixel math on non-square crops before upload. That single habit prevents most first-upload rejections and avoids shipping bloated files your customers never asked for.

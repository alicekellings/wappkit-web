# License Retrieval

Wappkit does not need a traditional customer dashboard for license recovery.

## Recommended lookup inputs

- order ID
- purchase email

## What the page provides

After the lookup succeeds, the page shows the full license key. It can also move the one-device license binding after confirming the original order ID and purchase email.

## Moving to a new computer

1. Retrieve the license with the original order ID and purchase email.
2. Select **Move License to New Device** for the bound key.
3. Activate the same key inside the desktop app on the new computer.

One self-service device move is allowed every 30 days.

## Why this is preferred

- simpler than account recovery
- easier for users
- more suitable for license-based desktop tools
- easier to maintain than a full sign-in system

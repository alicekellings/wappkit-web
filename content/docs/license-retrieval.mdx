# License Retrieval

Wappkit does not need a traditional customer dashboard for license recovery.

## Recommended lookup inputs

- order ID
- purchase email

## Recommended result

After the lookup succeeds, the system should resend the full license to the original purchase email.

## Why this is preferred

- simpler than account recovery
- easier for users
- more suitable for license-based desktop tools
- easier to maintain than a full sign-in system

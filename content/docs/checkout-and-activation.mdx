# Checkout and Activation

Wappkit uses a lightweight checkout model designed for desktop and utility tools.

## Purchase flow

1. Open the tool page.
2. Start checkout with Creem.
3. Complete payment.
4. Receive a license.
5. Enter that license inside the app.

## Activation steps

1. Copy the license key from the checkout success page or the license retrieval page.
2. Open the purchased tool on your desktop.
3. Find the activation screen inside the app.
4. Paste the license key.
5. Confirm activation to unlock the paid version.

If a license is shown as `inactive`, that normally means it has been issued but has not been activated yet.

## One-device policy

Each Pro key is active on one computer at a time. To move to a replacement computer:

1. Open `/license/retrieve`.
2. Enter the original order ID and purchase email.
3. Select **Move License to New Device**.
4. Open the app on the new computer and activate it with the same key.

Self-service moves are available once every 30 days. The previous computer returns to Free mode after its next license check.

## If the key is lost

1. Open `/license/retrieve` on Wappkit.
2. Enter the original order ID.
3. Enter the same purchase email used during checkout.
4. Copy the key again and activate inside the tool.

## Why this model

- No user dashboard required
- Lower support overhead
- Faster path from purchase to activation
- Better fit for simple utility products

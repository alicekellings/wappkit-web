# Installation

Each Wappkit tool should keep installation simple and English-first.

## Recommended flow

1. Download the installer from the relevant product page.
2. Run the installer on the supported operating system.
3. Launch the app and verify the free or trial state.
4. Activate with a license if you purchased a paid version.

## Notes

- Keep system requirements visible on each product page.
- Avoid sending users through unnecessary account setup.
- If activation fails, use the license center before contacting support.
